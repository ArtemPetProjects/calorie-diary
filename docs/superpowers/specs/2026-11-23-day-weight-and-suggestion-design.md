# Дизайн: вес на дату, стрелки групп и крупнее подсказки (BL-075–BL-077)

Дата: 2026-11-23. Источник: сообщение пользователя после пятого APK.

## Намерение

Сделать вес во вкладке «День» редактируемым и привязанным к конкретной дате; добавить видимую стрелку сворачивания у групп приёмов пищи; увеличить шрифт подсказок продуктов на 1 пункт.

## Решение

1. **Вес по дате.** Новая таблица `weights(date TEXT PRIMARY KEY, kg REAL NOT NULL)`. БД версии 6; `onUpgrade` делает только `CREATE TABLE IF NOT EXISTS`, не удаляя данные. Методы `weightFor(date)` и `saveWeight(date, kg)`.
2. **UI веса.** Строка «Вес сегодня: …» становится кнопкой. По нажатию открывается диалог с весом на выбранную дату; сохранение вызывает `saveWeight(selectedDate, kg)` и `refresh()`. Кнопка показывает вес из таблицы по дате, при отсутствии — «назначить». Вес в профиле остаётся отдельным значением для расчёта «Моей схемы».
3. **Стрелки групп.** Заголовок группы получает префикс «▼» при раскрытии и «▶» при свёрнутом состоянии; клик по заголовку по-прежнему переключает состояние.
4. **Шрифт подсказок.** `item_suggestion.xml`: имя 14sp → 15sp, КБЖУ 11sp → 12sp.

## Проверка

- JVM-тест на чистую функцию форматирования веса, если она появится; иначе импорт/сборка.
- `gradlew test assembleDebug` — код 0, все тесты зелёные.
- Ручной smoke: назначить вес на сегодня, переключить дату и убедиться, что вес другой; свернуть/развернуть группу по стрелке; проверить размер шрифта подсказок.

## Оставлено исполнителю

- Точный вид подписи кнопки веса и цвет стрелки.
