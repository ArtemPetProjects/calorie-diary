# Дизайн: отложенное создание блюда, редактирование и визуал групп (BL-079–BL-082)

Дата: 2026-11-23. Источник: сообщение пользователя после шестого APK.

## Намерение

Позволить начать сборку блюда до готовки, отложить её компактной кнопкой и вернуться после приготовления, чтобы указать итоговый вес. Добавить редактирование своих продуктов/блюд и увеличить читаемость списка приёмов пищи.

## Решение

1. **Отложенное блюдо.** Новая таблица `dish_drafts(id INTEGER PRIMARY KEY CHECK(id=1), items_json TEXT)`; БД версии 7, только `CREATE TABLE IF NOT EXISTS`. Методы `saveDraft(items)`, `draftItems()`, `clearDraft()`. В `DishDialog` добавляется кнопка «Отложить»: сохраняет текущие ингредиенты и закрывается. На вкладке «День» появляется кнопка-плитка «Продолжить создание блюда», открывающая диалог с сохранёнными ингредиентами; после сохранения блюда черновик удаляется.
2. **Итоговый вес.** Поле «Итоговый вес блюда, г» остаётся в диалоге и становится обязательным только при финальном сохранении; при отложенном создании оно не требуется.
3. **Редактирование.** Свои продукты редактируются в каталоге «Мои продукты» по КБЖУ и калорийности; свои блюда — в том же диалоге конструктора, включая итоговый вес. Сущёствующие формы уже это умеют — проверить и зафиксировать, при необходимости добавить явную кнопку «Сохранить изменения».
4. **Визуал.** Шрифт строк еды 14→15sp и 12→13sp, заголовок группы 14→15sp; рамка группы 1dp→2dp.

## Проверка

- `gradlew test assembleDebug` — код 0, тесты зелёные.
- Ручной smoke: добавить ингредиенты → отложить → плитка → продолжить → указать вес → сохранить; отредактировать продукт и блюдо; проверить размер шрифта и рамку.

## Оставлено исполнителю

- Точный вид плитки «Продолжить создание» и формат хранения черновика (JSON снимков ингредиентов).
