# Дизайн: финальные правки UI после повторного теста (BL-104)

Дата: 2026-11-24. Источник: повторный отзыв пользователя.

## Причины

1. **Клавиатура.** Режим `SOFT_INPUT_STATE_VISIBLE` выставляется в `OnShowListener`, то есть после показа окна; `SHOW_IMPLICIT` на этом этапе системой игнорируется. Нужно выставлять `SOFT_INPUT_STATE_ALWAYS_VISIBLE or SOFT_INPUT_ADJUST_RESIZE` до `show()`, а сам вызов IME делать только когда поле и окно уже прикреплены, через `OnGlobalLayoutListener`.
2. **Ширина списка.** В `DayView.showAddDialog` стоит `dropDownWidth = MATCH_PARENT`. Нужно после разметки брать фактическую ширину поля и отнимать 20dp.
3. **Цвет недавних.** Цвет применялся в `ProductAdapter` каталога, но не в `SuggestionAdapter` выпадающего списка. Нужно красить `suggestionName` для id из `recentProductIds()`.
4. **Цвета групп.** Четыре разных оттенка приёмов пищи отменяются: это один блок «День». Вместо этого у блоков «День», «Продукты», «Профиль» появляются свои акцентные цвета (зелёный, синий, фиолетовый) в виде тонкой полосы вверху экрана и подсветки активной вкладки.

## Принципы визуала после анализа гайдов

По Material Design 3 и доступным публикациям: colour roles (primary/secondary/surface вместо случайных оттенков), достаточный контраст подписей и значений, 8dp-система отступов, явная типографическая иерархия и короткие подписи элементов управления. Применяем это так: каждый блок экрана получает свою роль-акцент,внутри блока остаётся нейтральным; все отступы — кратны 4/8dp; заголовки полужирные и крупнее basic текста; второстепенный текст контрастный, но слабее основного; подписи кнопок короткие, чтобы не ломать геометрию.

## Решение

- Добавить `Dialog.prepareForKeyboard()` с режимом `ALWAYS_VISIBLE or ADJUST_RESIZE`, вызывать его сразу после `.create()` во всех диалогах с полями.
- В `focusAndShowKeyboard` показывать IME из `OnGlobalLayoutListener` после проверки прикрепления поля и окна.
- В `DayView` заменить `MATCH_PARENT` на фактическую ширину поля минус 20dp.
- В `SuggestionAdapter` хранить `recentIds` как `Set<Long>`, красить имя недавнего продукта в акцентный голубой, остальные — в стандартный цвет темы.
- Вернуть группам приёмов пищи общий нейтральный border; убрать использование четырёх drawable, файлы оставить на диске без применения.
- Добавить атрибуты `blockDay`, `blockProducts`, `blockProfile`; тонкие цветные полосы в трёх фрагментах; активная вкладка получает цвет соответствующего блока.
- Увеличить шрифт на 1sp во всех видимых элементах: кнопки, строки еды и продуктов, подсказки, заголовки групп, поля ввода, подписи полосок.
- Никаких изменений БД и ассетов; версия остаётся 10.

## Проверка

Обязательны: `gradlew test assembleDebug` с кодом 0 и подсчётом тестов; распаковка APK и парсинг обоих JSON через `json.loads`; симуляция миграции на копии БД; проверка отсутствия CJK в новых файлах; актуальные размер и SHA256 APK.
