# Дизайн: быстрый выбор продукта (BL-083–BL-087)

Дата: 2026-11-23. Источник: сообщение пользователя после седьмого APK.

## Намерение

Диалог добавления продукта должен открываться сразу со списком, длинным выпадающим списком, курсором в поле и клавиатурой. Недавно использованные пользователем продукты должны быть первыми при совпадении с вводом.

## Решение

1. **История использования.** Таблица `product_usage(product_id INTEGER PRIMARY KEY, used_at INTEGER)`; БД версии 8, `CREATE TABLE IF NOT EXISTS`. `markUsed(productId)` вызывается при сохранении записи в день и при сохранении блюда с ингредиентами. `recentProductIds()` возвращает множество id.
2. **Ранжирование.** Чистая функция `rankProductNamesWithRecent(names, query, recentNames)` с приоритетом: недавние совпадения → остальные startsWith → остальные contains. В адаптере recentNames строятся из `recentProductIds()`.
3. **Диалог.** `AlertDialog` открывается с `Gravity.TOP`, `WindowManager.LayoutParams.MATCH_PARENT` по ширине; `setSoftInputMode(SOFT_INPUT_STATE_VISIBLE)`. После показа: `productInput.requestFocus()`, `productInput.post { showDropDown() }`. `dropDownHeight` увеличен до ~480 dp, `dropDownWidth = MATCH_PARENT`.
4. **Мгновенный поиск.** Первый символ сразу фильтрует список через стандартный `AutoCompleteTextView` + кастомный `Filter`; список уже открыт, поэтому результат виден сразу.
5. **Недавние = все использованные.** История не ограничена по времени; при нажатии «Добавить продукт» без ввода список открывается и показывает использованные продукты первыми.

## Проверка

- JVM-тест приоритета недавних названий продуктов.
- `gradlew test assembleDebug` — код 0.
- Ручной smoke: добавить продукт → курсор и клавиатура, список открыт, недавние сверху, ввод первого символа фильтрует.

## Оставлено исполнителю

- Точная высота выпадающего списка и подписи кнопок.
